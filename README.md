# 🏯 Karunada Kote

### Karnataka's Fort Explorer

> *"Karunada Kote" (ಕರ್ನಾಡದ ಕೋಟೆ) means "Forts of Karnataka" in Kannada.*

[![API](https://img.shields.io/badge/API-26%2B-brightgreen?style=for-the-badge)](https://android-arsenal.com/api?level=26)

## ✨ Features

<div align="center">

| Feature | Description |
|---------|-------------|
| 🗺️ **Interactive Fort Map** | Explore all 30 Karnataka forts on OpenStreetMap with custom markers & route overlays |
| 🤖 **AI Historical Stories** | Rich narratives powered by Google Gemini 2.0 Flash — tap "✨ Generate AI History" on any fort |
| 📱 **Fort Detail Sheets** | Swipeable bottom sheet with dynasty, year, type, district, highlights & descriptions |
| 🎵 **Ambient Soundscape** | Atmospheric audio evoking ancient fortresses while you explore |
| ✅ **Visit Tracker** | Mark forts as visited; your progress persists across sessions |

## 🚀 Usage

### Getting Started

1. **Launch the App** → You'll see an animated splash screen
2. **Login/Sign Up** → Create an account or log in
3. **Explore Forts** → Browse the list of 30 Karnataka forts
4. **View Details** → Tap any fort to see its history, dynasty, and highlights
5. **Generate AI Story** → Click "✨ Generate AI History" for immersive narratives
6. **Explore on Map** → Tap the map icon to see fort locations on OpenStreetMap
7. **Mark as Visited** → Track your fort exploration journey

### Key Features Guide

| Action | How to Use |
|--------|------------|
| **Search Forts** | Use the search bar in the fort list screen |
| **View on Map** | Tap the map icon on any fort card |
| **AI History** | Tap "✨ Generate AI History" in fort details (requires internet) |
| **Mark Visited** | Use the checkbox in fort details |
| **Change Language** | Go to Profile → Settings → Language |
| **Logout** | Profile → Settings → Logout |

## 🔑 API Configuration

### Gemini API Key Setup

The app uses Google Gemini 2.0 Flash for AI-powered historical narratives.

1. **Get Your API Key**
   - Visit [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Sign in with your Google account
   - Click **"Create API Key"**
   - Copy the generated key

2. **Add to Project**
   - Open/create `local.properties` in the project root
   - Add: `GEMINI_API_KEY=your_api_key_here`

3. **Security Notice**
   - The API key is injected at build time via `BuildConfig`
   - `local.properties` is git-ignored by default
   - **Never** commit API keys to version control

### Offline Functionality

- ✅ Fort browsing works **completely offline**
- ✅ Map viewing works offline (cached tiles)
- ✅ Visit tracking works offline
- ❌ AI story generation requires internet + valid API key

## 🌐 Bilingual Support

Karunada Kote supports both **English** and **ಕನ್ನಡ (Kannada)** languages.

### Language Files

- **English:** `res/values/strings.xml`
- **Kannada:** `res/values-kn/strings.xml`

### Switching Languages

The app automatically detects your device language. To manually switch:

1. Go to **Profile** → **Settings**
2. Select **Language / ಭಾಷೆ**
3. Choose **English** or **ಕನ್ನಡ**
