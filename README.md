# 🏯 Karunada Kote — Karnataka's Fort Explorer

> *"Karunada Kote" (ಕರ್ನಾಡದ ಕೋಟೆ) means "Forts of Karnataka" in Kannada.*

An immersive Android app that brings Karnataka's 30 historical forts to life — complete with an interactive OSM map, AI-generated historical stories powered by Google Gemini 2.0, ambient soundscapes, and bilingual (Kannada + English) support.

## 🌟 Features

- **Interactive Fort Map** — Explore all 30 Karnataka forts plotted on an OpenStreetMap with custom markers and route overlays
- **AI Historical Stories** — Tap "✨ Generate AI History" on any fort to get a rich narrative generated by Google Gemini 2.0 Flash
- **Fort Detail Bottom Sheet** — Swipeable bottom sheet showing dynasty, year built, fort type, district, highlights, and full description
- **Ambient Soundscape** — Atmospheric audio that plays while browsing, evoking the feel of ancient fortresses
- **Visited Fort Tracker** — Mark forts as visited; your progress is saved locally across sessions
- **Search & Filter** — Instantly search forts by name from the main list
- **User Authentication** — Login/signup flow with session management using SharedPreferences
- **Bilingual Support** — UI strings available in both English and Kannada (ಕನ್ನಡ)
- **Shimmer Loading** — Polished shimmer placeholders while fort data loads
- **Dark Mode Ready** — Separate night-mode color resources included

## ⚙️ Setup & Installation

### Prerequisites

- Android Studio Hedgehog (2023.1.1) or later
- Android device / emulator running API 26+
- A [Google Gemini API key](https://aistudio.google.com/app/apikey) *(free tier available)*

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/<your-username>/KarunadaKote.git
   cd KarunadaKote
   ```

2. **Add your Gemini API key**

   Create a `local.properties` file in the project root (next to `settings.gradle.kts`) and add:
   ```properties
   sdk.dir=/path/to/your/Android/sdk
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. **Open in Android Studio**
  - File → Open → select the `KarunadaKote` folder
  - Wait for Gradle sync to complete

4. **Run the app**
  - Select a device (emulator or physical) with API 26+
  - Click **Run ▶** or press `Shift + F10`

> **Note:** The fort list and map work fully offline. Only the "✨ Generate AI History" feature requires an internet connection and a valid Gemini API key.

---

## 🔑 API Key Security

The Gemini API key is injected at build time via `BuildConfig.GEMINI_API_KEY` from `local.properties`, which is **git-ignored by default**. Never commit your `local.properties` file.
